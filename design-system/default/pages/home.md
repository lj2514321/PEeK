# 首页规则

继承 [MASTER](../MASTER.md)，以下规则只适用于首页与首次连接流程。

## 单一任务

未连接时：首页只负责让用户理解产品并成功找到服务器；检测到服务器后自然进入登录。已登录时，主操作切换为进入媒体库。

## 结构

1. 顶部命令栏：页面标题、全局搜索入口、连接/用户状态。
2. 影院主舞台：左侧价值说明和唯一主 CTA，右侧展示 Server → Player → Screen 的视觉链路。
3. 播放链路：服务器、libmpv、凭据三个状态卡，必须显示文字状态。
4. 底部能力标签：原码优先、多音轨与字幕、进度同步，保持低视觉权重。

## 状态

- 未检测：金色 CTA“添加媒体服务器”。
- 已发现未登录：金色 CTA“登录到服务器”，次操作“更换服务器”。
- 已登录：金色 CTA“打开媒体库”，用户与服务状态在顶部可见。
- 加载：按钮内进度，不清空背景内容。
- 错误：字段下方说明原因与修复方式，不只显示“失败”。

## 响应式

- ≥900px：主舞台左右 58/42 分栏。
- <900px：主舞台纵向排列，视觉链路高度固定，禁止在滚动视图内使用无界 Expanded。
- <720px：优先显示标题、说明与 CTA，能力标签允许换行。

## 视觉记忆点

一条细窄“放映光轨”贯穿主舞台和三个播放节点。光轨只表达实际连接进度，不做无限动画。
