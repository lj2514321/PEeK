# 首页规则

继承 [MASTER](../MASTER.md)，以下规则只适用于首页与首次连接流程。

## 单一任务

未连接时：首页只负责让用户理解产品并成功找到服务器；检测到服务器后自然进入登录。已登录时，首页只负责让用户找到下一部要看的内容，并能一步继续播放。

## 结构

1. 顶部命令栏：页面标题、全局搜索入口、连接/用户状态。
2. 影院主舞台：左侧价值说明和唯一主 CTA，右侧展示 Server → Player → Screen 的视觉链路。
3. 播放链路：服务器、libmpv、凭据三个状态卡，必须显示文字状态。
4. 底部能力标签：原码优先、多音轨与字幕、进度同步，保持低视觉权重。

## 状态

- 未检测：金色 CTA“添加媒体服务器”。
- 已发现未登录：金色 CTA“登录到服务器”，次操作“更换服务器”。
- 已登录：续播主舞台使用金色 CTA“继续播放”，用户与服务状态在顶部可见。
- 加载：按钮内进度，不清空背景内容。
- 错误：字段下方说明原因与修复方式，不只显示“失败”。

## 响应式

- ≥900px：主舞台左右 58/42 分栏。
- <900px：主舞台纵向排列，视觉链路高度固定，禁止在滚动视图内使用无界 Expanded。
- <720px：优先显示标题、说明与 CTA，能力标签允许换行。

## 已登录内容首页

1. 顶部问候：用户名、当前服务器和安静的刷新操作。
2. 每日推荐主舞台：展示 2–6 条服务器推荐；推荐不可用时依次回退到继续观看和最近添加内容。
3. 内容轨道：继续观看、最近添加的电影、最新剧集；空分区隐藏，错误分区独立恢复。
4. 主舞台允许直接播放，轨道卡片进入详情页，播放返回后刷新进度。

- 推荐主舞台每 5 秒切换，鼠标悬停时暂停；提供上一条、下一条和真实序号，不使用无意义装饰圆点。
- 推荐数据按本地自然日缓存：跨过 00:00 后仅刷新推荐分区；应用未运行或不在首页时，下次进入首页补刷新。同一天不后台重复请求，手动刷新除外。
- 系统关闭动画时停止自动轮播并使用无动画翻页。
- 主舞台用一条聚光金进度光轨表达实际观看位置，这是登录后首页唯一的强装饰。
- 媒体卡片无描边、无常驻玻璃容器，以海报和剧照作为视觉层级。
- ≥720px 使用 430px 高主舞台和横向轨道；<720px 使用 410px 主舞台、较窄卡片与横向滑动。
- 加载态保持与正式内容相同尺寸，不使用持续闪烁动画；局部请求失败不得清空其他分区。

## 视觉记忆点

一条细窄“放映光轨”贯穿主舞台和三个播放节点。光轨只表达实际连接进度，不做无限动画。
