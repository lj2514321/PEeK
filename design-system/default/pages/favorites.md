# 收藏页规则

继承 [MASTER](../MASTER.md)，以下规则只适用于一级收藏页。

## 页面职责

收藏页集中展示当前用户跨所有媒体库收藏的电影、剧集、单集、视频与音频。它是快速回到明确喜欢内容的一级入口，不承担媒体库的完整筛选和层级浏览职责。

## 结构

1. 页首使用心形聚光标记、`YOUR COLLECTION` 眉题、收藏总数和当前服务器。
2. 主体使用与媒体库一致的响应式海报网格，保留播放进度与已观看状态。
3. 海报右上角提供明确的取消收藏按钮，点击区至少 48×48px；卡片其余区域进入详情。
4. 加载更多使用当前页面底部反馈，不清空已加载收藏。

## 状态与反馈

- 首次加载保持安静的居中进度状态，禁止闪烁骨架。
- 无收藏时解释收藏入口，并提供“去媒体库看看”，禁止只显示空白网格。
- 取消收藏后立即移除卡片并显示可撤销 SnackBar；失败时保留卡片并说明原因。
- 从详情页返回后刷新收藏，确保详情页取消收藏能及时反映。
- 未登录状态提供返回首页连接入口；401/403 继续走全局会话失效流程。

## 响应式与无障碍

- <520px 两列，520–779px 三列，780–1039px 四列，1040–1239px 五列，更宽六列。
- 收藏按钮必须同时有心形图标、Tooltip 和语义标签，不能只靠金色表达状态。
- 页面刷新按钮、空状态动作和海报卡均可通过键盘访问，焦点顺序与视觉顺序一致。
