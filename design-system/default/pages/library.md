# 媒体库规则

继承 [MASTER](../MASTER.md)，以下规则适用于媒体库浏览、筛选和批量管理。

## 信息层级

1. 媒体库选择器：保持横向内容轨，当前库同时使用表面、文字和语义选中态。
2. 路径与标题：面包屑在筛选工具栏之前，始终说明当前浏览层级。
3. 查询工具栏：按“排序 → 筛选 → 密度 → 选择”的使用频率排列；窄屏允许换行，不隐藏核心操作。
4. 媒体网格：海报优先，标题与类型/年份为二级信息，收藏、已观看和进度只占用海报角落。

## 筛选与密度

- 排序按钮直接显示当前规则，选择后立即重新查询。
- 筛选对话框按内容类型、观看状态、年份分组；年份错误紧邻输入框，重置与取消始终可见。
- 激活筛选后在入口显示条件数量；无结果状态提供“清除筛选”，不得只显示空白网格。
- 宽松、标准、紧凑三档只调整列数与间距，不改变数据、不重置滚动层级，也不触发网络请求。

## 批量模式

- 用户可通过“选择”入口或长按海报进入；进入后单击海报只切换选择，不打开详情。
- 工具栏显示已选数量、全选已加载、收藏/取消收藏、标记已观看/未观看和退出。
- 操作期间禁用重复提交并显示文字与进度；完成后退出批量模式，以 SnackBar 提供一次撤销机会。
- 批量目标只包含当前已加载并明确选中的条目，不暗中选择未加载分页。

## 响应式与无障碍

- 所有工具栏按钮和选择控件交互高度至少 44px，图标按钮必须提供 Tooltip 与 Semantics。
- 375px 宽度下工具栏和批量操作允许多行，不出现横向溢出；对话框内容可纵向滚动。
- 收藏、已观看、选择和忙碌状态必须同时使用图标与文字或语义标签，禁止只靠色彩表达。
