# 设置页规范

## 页面目标

让用户看清当前正在使用的 Jellyfin/Emby 放映源，并能安全地添加、切换、重新登录、退出或移除服务器账户。

## 结构

1. 页面标题与唯一主操作“添加服务器”。
2. 当前放映源舞台：服务器、用户、服务器数量和已登录数量。
3. 放映源机架：每个 ServerId/UserId 对应一个账户条目。
4. 安全说明：密码不保存，token 独立存放于 Windows 安全存储。

## 视觉与状态

- 当前放映源使用左侧 4px 聚光金光轨，这是本页唯一强装饰。
- 已登录但未激活使用靛蓝状态；当前使用为绿色；需要登录为中性灰，同时提供文字，不只依赖颜色。
- 服务器地址使用 Cascadia Mono，单行省略，不显示 token 或认证查询参数。
- <720px 时标题操作、当前源数据和账户操作纵向排列；≥720px 使用横向机架。
- 切换和重新登录使用安静的次级按钮；每屏只保留一个金色“添加服务器”主操作。

## 行为

- 新增服务器成功登录后成为当前放映源，原有账户保持登录。
- 切换账户不删除旧 token；首页、媒体库和搜索必须刷新到新账户上下文。
- 退出账号删除 token，但保留服务器资料并显示“需要登录”。
- 移除服务器资料前必须确认，并明确不会删除服务器端媒体或观看记录。
- 401/403 失效只执行一次清理，保留服务器资料并返回可重新登录状态。
- 所有非必要切换动画遵循系统“减少动画”。
