# PEeK 设计系统

> 页面实现先读取 `design-system/default/pages/[page].md`；页面规则覆盖本文件，其余规则继承本文件。

## 产品方向

- 产品：Jellyfin / Emby 桌面家庭影音播放器
- 风格：Stagecraft Cinema（舞台式暗场影院）+ Liquid VisionOS（流体空间玻璃拟态）
- 关键词：内容优先、沉浸深色、悬浮胶囊岛、氛围微光（Ambient Glow）、镜面高光边缘、聚光金、克制高级
- 设计参数：视觉变化 7/10、动效 4/10、密度 6/10
- 原则：海报和影片信息是主角，悬浮玻璃质感与空间氛围光负责建立现代影院沉浸感

## 色彩 Token

| Token | Hex | 用途 |
|---|---:|---|
| Canvas | `#08090D` | 应用底色，避免纯黑拖影 |
| Surface Low | `#0E1118` | 侧栏、低层容器 |
| Surface | `#151925` | 卡片、对话框 |
| Surface High | `#1D2230` | 悬停、选中与浮层 |
| Outline | `#2B3140` | 分隔线与边框 |
| Text Primary | `#F4F2ED` | 标题和主要信息 |
| Text Secondary | `#AEB4C0` | 正文和辅助信息 |
| Text Tertiary | `#9299A7` | 标签和禁用前提示 |
| Spotlight Gold | `#E2BD72` / `#FFD27D` | 唯一主操作、播放状态 |
| On Gold | `#19140B` | 金色表面上的文本和图标 |
| Projector Indigo | `#767BEA` | 焦点环、链接、次级强调与冷光氛围弥散 |
| Success | `#58C99A` | 已连接、已完成，同时配图标/文字 |
| Error | `#FF8585` | 错误，同时配图标/说明 |

禁止在组件内增加临时十六进制颜色；先补充语义 Token。主操作每屏最多一个金色 CTA。

## 字体

- 展示标题：`Segoe UI Variable Display`，中文回退 `Microsoft YaHei UI`
- 正文：`Segoe UI Variable Text`，中文回退 `Microsoft YaHei UI`
- 数据/时间：`Cascadia Mono`，回退 `Consolas`
- 字阶：12 / 14 / 16 / 18 / 24 / 32 / 48
- 正文最小 14px，常规正文 16px，行高 1.5–1.65
- 大标题 600–700，正文 400，标签 500–600

## 布局与间距

- 使用 4/8pt 网格：4、8、12、16、24、32、48、64
- 桌面内容最大宽度 1280px
- ≥1040px：224px 带文字侧栏
- 720–1039px：80px 紧凑侧栏，但保留 Tooltip 与语义标签
- <720px：底部导航，最多五项
- 一级导航切换必须保留各页滚动位置与操作现场；重复选择当前首页或媒体库时回到顶部
- ≥1040px 的文字侧栏允许用户主动收起为 80px 图标栏；收起态保留 Tooltip、语义标签和激活光轨，切换使用 240ms 空间连续动画
- Windows 原生窗口在首帧显示前进入 frameless，不保留隐藏标题栏的缩放框、白边或整宽自绘窗框；最小化/最大化/关闭按钮悬浮整合进页面栏，播放器沉浸时全部退出画面
- Windows 11 窗口态使用系统标准圆角；最大化、贴靠和全屏由系统保持直角，不在 Flutter 内容层伪造四角
- 可点击区域最小 48×48px，交互项间距至少 8px
- 圆角：按钮 10px、输入框 12px、卡片 16px、主舞台 24px、操作胶囊与浮空控制岛 28px/Stadium

## 层级与效果

- 采用 VisionOS 空间流体玻璃拟态（Spatial Glass）：悬浮胶囊岛、物理级折射微边框与双层空间投影。
- 普通卡片：1px Outline，海报卡片支持背光溢出（`PosterAmbientGlow`）营造沉浸漫反射。
- 浮空胶囊与控制岛：采用 `AppGlass.visionOSDecoration`，迎光面采用 1.2px 半透白色渐变反光高光（Specular Rim Light），底部具有深邃接触阴影（blur 42）与蓝紫微光弥散层。
- 模糊：控制面板、悬浮小窗与侧栏采用平滑毛玻璃 `ImageFilter.blur(sigmaX: 20-28, sigmaY: 20-28)`，透出底层视频动态光影与环境色。
- 按钮形态：核心交互操作采用优雅的药丸胶囊（`StadiumBorder`），主操作按钮聚光金搭配微光环境漫反射。
- 渐变用于影片背景、主舞台与玻璃边框折射，不堆叠无序渐变。

## 动效

- Fast 180ms：hover、pressed、focus
- Standard 240ms：内容替换、导航选中
- Slow 320ms：对话框和页面层级进入
- 曲线：进入 `easeOutCubic`，退出 `easeInCubic`
- 只动画透明度和位移；禁止持续循环的装饰动画
- `MediaQuery.disableAnimations == true` 时禁用非必要动效

## 组件准则

- 导航：图标与文字同时出现；选中态使用金色光轨、字重和表面色，不只依赖颜色
- 按钮：主按钮金色，次按钮描边/文字；加载时禁用并显示进度
- 输入：始终显示标签；错误紧邻字段并提供恢复方法；支持密码显示与系统自动填充
- 卡片：媒体卡固定宽高比，图片加载前预留空间；大量列表使用惰性网格
- 媒体状态：收藏使用心形图标，已观看使用勾选图标；批量模式增加明确选择圈和数量文字，不只改变卡片边框
- 工具栏：排序、筛选、密度和批量入口允许在窄屏自然换行；筛选数量与当前排序必须直接可见
- 横向内容轨：移动端直接滑动；≥640px 显示前后方向按钮，按钮必须反映真实可滚动状态
- 图片：加载态使用静止暗场帧，不使用闪烁骨架；失败态显示低对比度损坏图标，命中后仅做 Fast 淡入并遵循“减少动画”
- 图标：Flutter Material Rounded 作为当前统一图标族，同层级不混用填充与描边语义
- 焦点：所有键盘可交互控件显示 2px 靛蓝或聚光金焦点环

## 无障碍底线

- 正文对比度 ≥4.5:1，大文本和大型图标 ≥3:1
- 色彩状态同时提供图标和文字
- Tab 顺序与视觉顺序一致，Escape 可关闭对话框
- 图标按钮必须有 Tooltip/Semantics 标签
- 文本缩放到 150% 时不遮挡主要操作
