# PEeK 设计系统

> 页面实现先读取 `design-system/default/pages/[page].md`；页面规则覆盖本文件，其余规则继承本文件。

## 产品方向

- 产品：Jellyfin / Emby 桌面家庭影音播放器
- 风格：Stagecraft Cinema（舞台式暗场影院）
- 关键词：内容优先、沉浸深色、轻薄分层、聚光金、克制高级
- 设计参数：视觉变化 6/10、动效 4/10、密度 6/10
- 原则：海报和影片信息是主角，装饰只负责建立影院氛围

## 色彩 Token

| Token | Hex | 用途 |
|---|---:|---|
| Canvas | `#08090D` | 应用底色，避免纯黑拖影 |
| Surface Low | `#0E1118` | 侧栏、低层容器 |
| Surface | `#151925` | 卡片、对话框 |
| Surface High | `#1D2230` | 悬停、选中与浮层 |
| Outline | `#2B3140` | 分隔线与边框 |
| Text Primary | `#F4F2ED` | 标题和主要信息 |
| Text Secondary | `#AEB4C0` | 正文和辅助信息 |
| Text Tertiary | `#9299A7` | 标签和禁用前提示 |
| Spotlight Gold | `#E2BD72` | 唯一主操作、播放状态 |
| On Gold | `#19140B` | 金色表面上的文本和图标 |
| Projector Indigo | `#767BEA` | 焦点环、链接、次级强调 |
| Success | `#58C99A` | 已连接、已完成，同时配图标/文字 |
| Error | `#FF8585` | 错误，同时配图标/说明 |

禁止在组件内增加临时十六进制颜色；先补充语义 Token。主操作每屏最多一个金色 CTA。

## 字体

- 展示标题：`Segoe UI Variable Display`，中文回退 `Microsoft YaHei UI`
- 正文：`Segoe UI Variable Text`，中文回退 `Microsoft YaHei UI`
- 数据/时间：`Cascadia Mono`，回退 `Consolas`
- 字阶：12 / 14 / 16 / 18 / 24 / 32 / 48
- 正文最小 14px，常规正文 16px，行高 1.5–1.65
- 大标题 600–700，正文 400，标签 500–600

## 布局与间距

- 使用 4/8pt 网格：4、8、12、16、24、32、48、64
- 桌面内容最大宽度 1280px
- ≥1040px：224px 带文字侧栏
- 720–1039px：80px 紧凑侧栏，但保留 Tooltip 与语义标签
- <720px：底部导航，最多四项
- 可点击区域最小 48×48px，交互项间距至少 8px
- 圆角：按钮 10px、输入框 12px、卡片 16px、主舞台 24px

## 层级与效果

- 主要靠表面明度和边框建立层级，不堆叠阴影
- 普通卡片：1px Outline，无阴影
- 浮层：`0 18 48 rgba(0,0,0,.32)`，可使用 40–55% scrim
- 模糊只用于对话框背景隔离，不作为常驻装饰
- 渐变仅用于影片背景或主舞台，不用于所有按钮/卡片

## 动效

- Fast 180ms：hover、pressed、focus
- Standard 240ms：内容替换、导航选中
- Slow 320ms：对话框和页面层级进入
- 曲线：进入 `easeOutCubic`，退出 `easeInCubic`
- 只动画透明度和位移；禁止持续循环的装饰动画
- `MediaQuery.disableAnimations == true` 时禁用非必要动效

## 组件准则

- 导航：图标与文字同时出现；选中态使用金色光轨、字重和表面色，不只依赖颜色
- 按钮：主按钮金色，次按钮描边/文字；加载时禁用并显示进度
- 输入：始终显示标签；错误紧邻字段并提供恢复方法；支持密码显示与系统自动填充
- 卡片：媒体卡固定宽高比，图片加载前预留空间；大量列表使用惰性网格
- 图标：Flutter Material Rounded 作为当前统一图标族，同层级不混用填充与描边语义
- 焦点：所有键盘可交互控件显示 2px 靛蓝或聚光金焦点环

## 无障碍底线

- 正文对比度 ≥4.5:1，大文本和大型图标 ≥3:1
- 色彩状态同时提供图标和文字
- Tab 顺序与视觉顺序一致，Escape 可关闭对话框
- 图标按钮必须有 Tooltip/Semantics 标签
- 文本缩放到 150% 时不遮挡主要操作
