- [x] Flutter Windows 工程
- [x] 首版视觉系统与响应式桌面壳层
- [x] Riverpod、Dio、JSON 本地存储、安全存储和 media_kit 依赖
- [x] Jellyfin/Emby 服务发现

- [x] Jellyfin/Emby PlaybackInfo 适配

- [x] 硬件解码设置与失败回退
